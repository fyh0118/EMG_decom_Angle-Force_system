一、项目概述
--------------------------------------------------------------------------------
  基于高密度肌电(HD-sEMG)分解的腕关节运动解码与康复评估系统。
  MATLAB GUI 应用，支持模型验证和康复评估两种模式。

  核心技术链路：
  双64通道HD-sEMG采集 → 在线ICA分解(预训练模板) → MU发放序列
  → CNN-BiLSTM双输出预测(角度+力) → 康复评估(ROM/力量/稳定性综合评分)


二、使用说明
--------------------------------------------------------------------------------

  【启动】
    双击 EMGDecom.exe → 进入登录界面 → 选择模式：
      - "模型验证系统"：数据采集 → 分解 → 预测，验证算法准确性
      - "康复评估系统"：完整流程 + 康复评估 + 数据管理

  【模式选择界面】
    两个大按钮选择进入模式，右上角可返回登录。

  【数据采集 Tab】
    1. 点击"加载数据"，选择被试的 .mat 文件
    2. 屈肌/伸肌各64通道 EMG 信号自动加载
    3. 康复评估模式下，额外加载角度和力标签数据
    4. 波形图实时预览

  【肌电分解 Tab】
    1. 左侧面板自动识别被试编号，选择动作类型(G01-G04)
    2. 模板状态自动检测（绿色=已匹配，红色=未找到）
    3. 点击"开始在线分解" → Python桥自动执行ICA分解
       - 生成MU发放序列（屈肌+伸肌）
       - 光栅图显示在左右两侧
    4. 下拉选择MU编号 → 查看MUAP波形
    5. 勾选"叠加发放"可叠加显示spike时刻

  【双输出预测 Tab】
    1. 分解完成后自动进入
    2. 特征提取：累计脉冲计数 + sqrt变换
    3. CNN-BiLSTM模型输出预测角度和力
    4. 预测值 vs 真实值对比曲线

  【康复评估 Tab】（仅康复评估模式）
    1. 患者信息区：填写姓名、目标ROM(默认90°)、目标力量(默认50N)
    2. 选择动作类型(屈伸/旋转)
    3. 点击"刷新评估" → 三指标卡片更新：
       - ROM运动能力：最大屈曲/伸展角度 vs 目标
       - 力量能力：峰值/平均力 vs 目标
       - 动作稳定性：标准差评估
    4. 综合评分自动计算，等级：优秀/良好/中等/较差/差
    5. "导出报告"按钮 → 生成PDF评估报告
    6. 评估记录自动保存到 records/ 目录

  【数据管理 Tab】（仅康复评估模式）
    1. 左上：记录表格，支持按患者/动作/等级查询
    2. 右上：ROM/力量/综合评分趋势折线图
    3. 左下：批量导入导出（MAT/CSV/PDF）
    4. 右下：8项统计（总患者数/总次数/平均分/最佳分等）
    5. 双击表格行 → 弹出详情窗口
    6. "演示数据"按钮 → 一键生成3患者×5次=15条测试记录

四、可移植部署
--------------------------------------------------------------------------------
  目标环境：Windows 64位，无需安装 MATLAB 或 Python

  【安装到新电脑】
    1. 安装 MATLAB Runtime R2024a（免费，下载地址见后）
    2. 将 build_output/ 整个文件夹拷贝到目标电脑
    3. 双击 EMGDecom.exe 运行

  【MATLAB Runtime 下载】
    https://www.mathworks.com/products/compiler/mcr/index.html
    选择 R2024a 版本 → Windows 64-bit

  【重新编译方法】（需要 MATLAB + MATLAB Compiler + 学校账号）
    1. 先打包 Python 桥：
       cd build_pyinstaller
       pyinstaller --clean decompose_python_bridge.spec
       （生成 dist/decompose_python_bridge.exe，内含 Python 3.7 + 全部依赖）
    2. MATLAB 运行 build_app() 生成 build_output/EMGDecom.exe

  【关键文件说明】
    decompose_python_bridge.py    Python 在线分解桥接脚本（开发用）
    decompose_python_bridge.exe   PyInstaller 打包的独立 EXE（自带 Python）
    build_app.m                  MATLAB Compiler 打包脚本
    模板/                         预训练 ICA 模型 + CNN 模型


五、模板文件结构
--------------------------------------------------------------------------------
  模板/
    S01/          ← 被试1
      G01/        ← 侧捏屈伸
        net.mat                   CNN 模型权重
        norm_params.mat           归一化参数
        *_ica_model_T*_dev0.pkl   屈肌侧 ICA 模型 (sklearn)
        *_ica_model_T*_dev1.pkl   伸肌侧 ICA 模型 (sklearn)
        *_center_T*_dev0.csv      屈肌侧聚类中心
        *_center_T*_dev1.csv      伸肌侧聚类中心
        *_valid_index_T*_dev0.csv 屈肌侧有效 MU 索引
        *_valid_index_T*_dev1.csv 伸肌侧有效 MU 索引
      G02/        ← 侧捏旋转
      G03/        ← 对捏屈伸
      G04/        ← 对捏旋转
    S02/          ← 被试2

  注意：.pkl 文件必须用 sklearn 0.22.1 + joblib 0.14.1 保存/加载
       桥 EXE 已固定打包此版本，无需担心兼容性


六、技术约定
--------------------------------------------------------------------------------
  - MATLAB R2018a+ 兼容
  - 窗口尺寸：1400×980
  - 浅色系 UI（#f0f5fa 底色，#264b75 蓝色主题，Microsoft YaHei 字体）
  - 力量单位：N（牛顿）
  - 采样率：2000 Hz（默认）
  - 动作类型：G01侧捏屈伸 / G02侧捏旋转 / G03对捏屈伸 / G04对捏旋转
  - 评估记录：%APPDATA%\肌电慧控\records\
